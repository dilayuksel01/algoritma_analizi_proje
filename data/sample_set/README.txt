CMP3005 Term Project - Sample set
=================================

Contents
  main_doc.txt          the document to check (30 sentences)
  documents/            document1.txt ... document20.txt
  expected_output.txt   the result a correct program should print

20 of the 30 sentences in main_doc.txt were copied from 5 of the documents:
13 copied exactly, 7 with small edits (a word added, removed, replaced, or two
neighbouring words swapped). The other 10 sentences appear in no document, so
every other document has 0.0% similarity.

Run your program in this folder (it reads main_doc.txt and documents/ itself)
and compare its output with expected_output.txt. The order of the sentence
pairs inside a block does not matter.

At your presentation you will receive a hidden test set with the same
structure but larger (about 200 documents and a longer main_doc.txt) and run
your program on it on your own laptop. Make sure it runs from a folder you
are given, without changes to the code.

Texts: U.S. State of the Union addresses (1790-1959) and Herman Melville's
Moby-Dick, both in the public domain.
